Web Viewer — Manual Test Guide

Verify the browser-based 3D rover viewer (web/) works, including the recent CSS fixFIXED that was hiding the working simulation behind a false error overlay.

1 Start a local server

This app must be served over HTTP — opening index.html directly by double-clicking it (a file:// URL) will trigger a "3D engine failed to load" message, by design, because browsers block module-style script loading over file://.

Open a terminal in the web/ folder and run:

cd path\to\lunar-rover-quantum\web
python -m http.server 8080
Expect: the terminal prints Serving HTTP on :: port 8080 and appears to hang — that's normal, it's the server running. Leave this terminal open.

2 Open it in a browser

Go to:

http://localhost:8080/index.html
Expect: you should see the 3D scene immediately — a lunar rover, scattered rocks, a terrain plane, an orange goal flag — not an error screen.
If you still see "3D engine failed to load": hard-refresh with Ctrl + Shift + R (this forces the browser to re-fetch style.css instead of using a cached pre-fix copy).

3 Check the HUD panels

Around the 3D view you should see, without clicking anything:

  • Top-left — "Lunar Rover" title + "Quantum Navigation · Phase 3 Simulation"
  • Left side — Telemetry (Speed, Heading, Position, Goal dist.), System (Battery, Gravity, Surface °C, Terrain), and a Mini Map with an orange dot
  • Right side — Drive controls (on-screen D-pad + max speed slider), Camera mode buttons (Chase / Orbit / Top), and a Quantum AI panel with three progress bars
  • Bottom — a status bar with driving instructions and a ROS2 launch command hint

4 Drive the rover

Click anywhere on the 3D canvas first (to give it keyboard focus), then try:

  • W / ↑ — drive forward
  • S / ↓ — reverse
  • A D / ← → — turn
  • Or use the on-screen D-pad buttons in the right-side "Drive" panel
Expect: the rover model moves across the terrain, the Speed and Position telemetry values update live, and the orange dot on the Mini Map moves too.

5 Try the other modes

  • Click Patrol AI (top tab) — the rover should start driving itself toward the goal flag
  • Click Orbit (right panel, under Camera) — drag with the mouse to rotate the view, scroll to zoom
  • Click Top — switches to a top-down view
  • Drag the Max speed slider — the value label should update as you drag

6 Confirm there are no console errors

Open DevTools (F12 or Ctrl+Shift+I) and click the Console tab.

Expect: no red error lines. Yellow warnings (if any) are usually harmless.

7 Stop the server

Back in the terminal from Step 1, press Ctrl+C to stop it.

What was actually broken (for reference)

web/css/style.css had a rule .load-error { display: flex; ... } with no [hidden] qualifier. The page's own JavaScript correctly detected that Three.js loaded fine and set the error box's hidden attribute — but that CSS rule overrode it and forced the error box to display anyway, every time, regardless of whether anything was actually wrong. The fix adds :not([hidden]) to the selector so the browser's default hiding behavior isn't overridden.
